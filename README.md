# Замер скорости скачивания файлов и видео

Консольный скрипт на Node.js: скачивает файл 10 раз или загружает HLS-видео
в двух качествах — 480p и 1080p. Запросы выполняются последовательно,
каждый ответ читается полностью. Результаты выводятся в таблицах.

## Запуск

Нужен Node.js 22+. Устанавливать зависимости не требуется.

```bash
git clone https://github.com/Waikizashi/stream-route-bench.git
cd stream-route-bench
```

Передайте адрес нужного файла:

```bash
node index.js "https://example.org/image.jpg"
```

В примере замените URL на существующую картинку или другой файл.
Тот же запуск через npm: `npm start -- "https://example.org/image.jpg"`.

## Видеопоток

Публичный тестовый поток Big Buck Bunny от Mux:

```bash
npm start -- --stream
```

Скрипт выбирает 480p и 1080p и скачивает первые **10 полных видеосегментов**
каждого качества: всего 20 последовательных загрузок. Это замер загрузки
фрагментов видео; проигрывание и сохранение всего фильма не выполняются.

Можно передать свой HLS-плейлист:

```bash
node index.js --stream "https://example.org/master.m3u8"
```

URL с расширением `.m3u8` автоматически включает видеорежим.
В master playlist должны быть доступны 480p и 1080p. Если передан media playlist
одного качества, скрипт скачает из него 10 сегментов с отметкой «Видео».
Поддерживаются незашифрованные самостоятельные MPEG-TS-сегменты.
fMP4, byte ranges, шифрование и LL-HLS не поддерживаются.

Поток по умолчанию: [тестовый поток Mux](https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8).
Загрузка плейлистов выполняется до замера и не входит в показатели видео.
Данные читаются по частям, без сохранения на диск. Для каждого запроса действует
ограничение 120 секунд, размер плейлиста ограничен 2 МиБ.

## Результат и единицы

Для каждого качества выводится отдельная таблица: номер запроса, статус,
время, объём и скорость. Первая и последняя загрузки отмечаются в столбце
«Завершение». В обычном терминале виден счётчик скачиваний и цветные заголовки.

В итоговой таблице сравниваются качества: количество успешных запросов,
среднее время, суммарный объём, время серии и скорость. Для двух качеств
добавляется общая строка «ИТОГО».

- Среднее время запроса — в миллисекундах.
- Общий объём — в байтах и МиБ. 1 МиБ = 1 048 576 байт.
- Скорость скачивания — в МиБ/с.

Среднее время — сумма времени запросов, делённая на количество попыток.
Скорость — общий объём в МиБ, делённый на суммарное время запросов в секундах.
Время каждого запроса включает ожидание ответа и полное чтение его тела.
В объём входят полученные данные тела ответа без HTTP-заголовков.

Ошибки отображаются в таблице; после ошибки запускается следующий запрос.
Время и полученные байты неудачных попыток также входят в итоговые показатели.
Код завершения: 0 — все загрузки успешны, 1 — ошибка параметров или подготовки,
2 — есть ошибки скачивания.

Справка: `npm start -- --help`. Внешних зависимостей нет.
